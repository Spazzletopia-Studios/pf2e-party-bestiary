# PF2e Party Bestiary

A Bestiary tab on every player's character sheet. Creatures the party has
met show up redacted, and facts unlock as the GM reveals them, a player
researches them in downtime, or the party studies a dragged-in stat block.

## Install

**The easy way (Windows):** download the SpazzMods installer
(https://github.com/Spazzletopia-Studios/spazzmods-installer/releases/latest),
run it, and click Install on PF2e Party Bestiary. No account needed.

**Without the installer:** paste this into Foundry's **Install Module →
Manifest URL** box:
`https://github.com/Spazzletopia-Studios/pf2e-party-bestiary/releases/latest/download/module.json`

## Using it

- Look for the paw-icon **Bestiary** tab on any player character sheet.
- Each known creature is a collapsed card — portrait, name, level, a
  one-line teaser — that expands on click, or search by name.
- Unknown facts show redacted with a **Research** button, rolled against
  the creature's real identification DC.
- Add a creature by search or by dragging one in from a compendium — it
  arrives fully locked until someone learns something about it.
- The GM can reveal any fact directly, or write table notes on a creature.
- Install **PF2e Encounter Console** too and the two work together with
  nothing extra to set up.
