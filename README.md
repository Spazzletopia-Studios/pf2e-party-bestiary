# PF2e Party Bestiary

A Bestiary tab on every player character sheet - redacted creature facts that unlock through play.

Install in Foundry VTT (Install Module > Manifest URL):
```https://github.com/Spazzletopia-Studios/pf2e-party-bestiary/releases/latest/download/module.json```

Part of the Spazzletopian PF2e mods. Free module.
